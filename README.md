# 李牧泽 · 个人主页

> 用途：第一次打开这个仓库的人。看完知道这是什么、怎么本地看、怎么改一处内容。

一个中文单页个人主页，发布在 https://luz7818.github.io/ 。
整个页面就是仓库根目录的一个 `index.html`，没有构建步骤、没有依赖、没有后端。

页面由 8 个小节组成：简介、科研、经历、论文、开源项目、荣誉、学生工作、联系。

## 30 秒看一遍

```bash
# 方式一：直接双击仓库根目录的 index.html（离线可用）
# 方式二：本地起一个静态服务器
python -m http.server 8000
# 然后浏览器打开 http://127.0.0.1:8000/
```

看线上版本是否已经是本仓库的内容：

```bash
curl -s https://luz7818.github.io/ | wc -c
```

输出的字节数与本地 `index.html` 一致，就说明线上就是这个版本。当前值以
[AGENTS.md](AGENTS.md) 的「当前状态」为准，不在这里复述。

## 改一处内容

不知道东西在哪个路径,先看 [目录说明.md](目录说明.md):整棵目录树、每个目录的入口都在里面,它只做导航。谁负责什么见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) 与各目录 README。

文案、配色、结构全部在 `index.html` 一个文件里，改完推 `main` 分支即发布。
加一条论文、加一个项目卡、换头像的具体步骤见 [上手手册](docs/GET-START.md)。

| 想改的东西 | 在文件里的位置 |
|---|---|
| 姓名、引导语、邮箱 | 顶部 hero 区与 `#contact` 小节 |
| 小节标题与正文 | `<section id="…">` 各自一块，共 8 个 |
| 项目卡片 | `#projects` 小节里的 `<article class="project">`，当前 5 张 |
| 配色 | `:root` 下的 14 个 CSS 自定义属性（`--ink`、`--teal`、`--paper` 等） |
| 图片 | `assets/`，逐个文件说明见 [assets/README.md](assets/README.md) |

## 发布是怎么生效的

仓库名是 `Luz7818.github.io`，GitHub Pages 把它当作用户站，直接从默认分支 `main`
的根目录发布，不经过任何构建：推上去就是线上。

| 路径 | 由谁发布 |
|---|---|
| `https://luz7818.github.io/` | 本仓库的 `index.html` |
| `https://luz7818.github.io/marx-cloud/` | **另一个仓库** `marx-cloud` 的 Pages |

因为用户站占据根路径，本仓库里不要再建 `marx-cloud/` 之类的目录，否则会和
那个项目页抢同一条 URL。

## 已知情况

1. 字体走系统栈（Inter → Segoe UI → 微软雅黑）。页面不分发字体文件，
   机器上没装 Inter 时实际看到的是后备字体，排版宽度会与设计稿有出入，
   截图对比时请注明是哪台机器。
2. 无测试、无 lint；CI 只有一条跑资源与锚点两类核对的最小工作流。可用的自检就是这两类，
   命令与判读写在 [docs/TESTING.md](docs/TESTING.md) 里。
3. 页面把姓名、学校、邮箱公开在互联网上。这是主页的目的，但改动时请留意不要
   顺手加上住址、电话等更敏感的信息。
4. 移动端只按 3 个断点（1100 / 920 / 640）做了适配，没有在真机上逐一验证过。
